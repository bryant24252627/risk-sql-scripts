# 风控核心指标计算SQL脚本
本仓库包含金融风控领域最核心的3个指标计算SQL，可直接在SQLite/MySQL中运行。

## 包含指标
1. **逾期率**：当期逾期余额/当期总贷款余额
2. **通过率**：审批通过数/总申请数
3. **M1→M2滚动率**：本期M2余额/上期M1余额

## 使用方法
1. 下载 `risk_indicators.sql` 文件。
2. 在SQLiteStudio/MySQL客户端中执行脚本。
3. 查看结果即可得到对应指标值。

## 运行结果示例
- 逾期率：74.14%
- 通过率：60.00%
- M1→M2滚动率：40.00%
